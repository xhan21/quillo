# 資料別の用語辞書

## 保存先と更新

利用者の辞書は `~/Library/Application Support/Quillo/Glossaries/<id>.json` に保存します。選択IDは既存のアプリ識別子のUserDefaultsに保存します。配布アプリのリソースに入れないため、アプリ更新で消えません。教材本文、発表者メモ、教材名を含む辞書は個人データとして扱い、公開リポジトリにコミットしないでください。

「設定 → 用語辞書 → 辞書を追加・更新…」から読み込みます。同じIDなら原子的に更新し、その辞書を選択します。別資料には別IDを使います。「使わない」で無効にできます。現在はファイルで編集・追加する方式です。

## JSON形式

```json
{
  "id": "example-material",
  "name": "授業用語の例",
  "entries": [
    {
      "terms": {
        "ja": "試作",
        "en": "prototype",
        "zh-Hans": "原型",
        "zh-Hant": "原型"
      },
      "aliases": { "ja": ["しさく"] }
    }
  ]
}
```

`aliases`は省略できます。対応言語はja、en、zh-Hans、zh-Hant。各項目に2言語以上が必要です。1辞書100項目、ファイル256KB、名称と各語80文字まで。同じ言語の同じ語を異なる項目に登録するとエラーになります。IDは英数字・ハイフン・アンダースコアのみ、80文字以内です。改行や制御文字は用語に入れられません。

読み方は別名として登録できます。誤変換された一般語を無差別に別名登録すると誤置換につながるため避けてください。1文字の語・記号は文中の用語置換から除外します。日本語は一致位置で長い複合語を優先し、英語は単語の途中に一致させません。活用形や未知の表記は自動で追加しません。

## 適用方法と制約

- 音声認識：正規語を優先し、別名も含めて最大100個のcontextualStringsを認識要求へ設定します。再認識の区切りにも再設定します。これは認識候補であり、カスタム音響モデルや発音モデルの学習ではありません。[Appleの説明](https://developer.apple.com/documentation/speech/sfspeechrecognitionrequest/contextualstrings)
- 字幕：macOS 15 TranslationSessionには辞書引数がありません。一致語を一時識別子へ置換して1回翻訳し、登録訳語へ戻します。識別子の欠落・重複・改変があれば原文で再翻訳し、不明な識別子を画面へ出しません。単語全体が完全一致する入力は辞書から直接返します。原文ログは変更しません。文法・語形・冠詞・多義語は不自然になる場合があり、文章全体の精度を保証する仕組みではありません。
- 要約：選択範囲に存在した語だけを、訳語対応のJSONとしてローカルAIへ渡します。辞書の語を理由に新しい内容を追加しないよう指示します。AIが原語の表記を残した場合は、入力で一致していた用語に限って登録訳語へ補正します。すでに正しい訳語になっている箇所は保護します。それ以外の言い換えが残る場合もあります。
- 辞書更新：進行中の古い字幕・要約を世代で除外し、現在の文章を更新します。要約キャッシュは無効化し、入力キーにも用語情報を含めます。画面共有や準備済みTranslationSessionを作り直しません。UIでは認識中の辞書変更を無効にし、認識候補が次回開始から確実に適用されるようにします。

## 確認

`zsh test.sh`に辞書の保存・再読込、検証、複合語優先、英語の単語境界、別名、繁体字、用語保持に失敗した際の通常翻訳、字幕の古い結果除外、要約キャッシュ変更のテストを含みます。`build/glossary-tests --live`はローカルOllamaを用いて架空の短文を英語・繁体字へ要約します。マイクや画面共有は使いません。ライブの音声認識精度は実際の教室で確認してください。

# Quilloを使う準備

[トップページへ](../README.md)

## 公開しているもの

- 現在は、開発用のソースコードを公開しています。
- 配布用のインストーラー・公証済みアプリ・自動更新は未提供です。
- 自分のMacでビルドすると、`Quillo.app`を作成できます。

## 必要な環境

- Apple Silicon搭載Mac（M1以降）。
- macOS 15以降。
- Xcode Command Line ToolsとmacOS 15対応SDK。
- 初回の言語データ・モデル取得用のインターネット接続。

## アプリを作成する

リポジトリを取得し、ターミナルで実行します。

```sh
git clone https://github.com/xhan21/quillo.git
cd quillo
zsh build.sh
```

- 作成先：`build/Quillo.app`。
- Finderで「アプリケーション」へ移動すると、FinderやSpotlightから開けます。
- 既存版を更新するときはQuilloを終了し、旧版を保管してから置き換えます。
- ビルドは開発用のアドホック署名です。一般配布向けのAppleの公証は行っていません。

## 音声字幕の準備

1. macOSの「システム設定 → キーボード → 音声入力」を確認します。
2. 使用する言語の端末内音声認識データを準備します。
3. Quilloで言語を選び、「翻訳を準備」を押します。初回はmacOSの言語データ取得の案内に従います。
4. 「話して字幕を出す」を押し、マイク・音声認識の許可を確認します。

- 対応言語：日本語、英語、中国語の簡体字・繁体字。
- 端末内認識を利用できない場合は案内を表示します。クラウド認識へ自動で切り替えません。
- マイクを使わずに確認する場合は、「設定 → 動作確認・字幕ログ」の文字入力を使えます。

## 資料要約の準備

- [Ollama](https://ollama.com/)を導入します。
- ローカルモデル`qwen3.5:9b`を準備します。モデルはアプリに同梱していません。
- Quilloは、Mac内で動くモデルだけを使います。モデルの自動ダウンロードは行いません。
- モデルが見つからない場合は、Ollamaの状態とモデル名を確認します。

準備ができたら、[使い方](USER_GUIDE.md)へ進んでください。要約モデルの選定・確認環境は[モデル評価](../MODEL-EVALUATION.md)に記載しています。

# 確認済みの動作と範囲

最終更新：2026-10-18。Apple Silicon、macOS 15.3.2、Swift 6.1／SDK 15.4で確認した開発用の試作です。

## 実装と動作確認

- Swift/AppKit/SwiftUIでビルドし、アドホック署名の検証に成功。
- 独立した字幕パネルの表示・移動・リサイズ、設定画面の再表示、背景色・濃さ・各言語の文字サイズの保存を確認。
- 日本語の音声認識と英訳の途中更新を短い読み上げ音声で確認。音声全体を正確には認識できなかったため、教室での精度・遅延を保証する確認にはしていない。
- 任意の日本語の文字入力をApple Translationで英訳し、原文のみ／翻訳のみ／原文＋翻訳の表示を確認。
- 原文のみへの切替でマイク・翻訳を初期化してしまう問題を修正。UIと同じメソッドで、準備中・翻訳中・待機中・停止後の切替と復帰を回帰テスト。実アプリでも原文のみで入力した2つの文章が、翻訳表示に戻すだけで英訳された。
- 単一ウィンドウの選択、指定範囲の画像取得、Vision OCRを確認。認識した文章からローカルOllamaで資料要約を生成。
- Qwen3.5 9Bによる架空教材の日本語・英語・簡体字・繁体字の要約、狭いパネルでの短縮を確認。モデル比較と実際の例はMODEL-EVALUATION.mdを参照。
- 要約パネルの大きな翻訳済み見出し、ドラッグ、サイズ変更、配色、位置固定を実アプリで確認。
- Quilloへの名称変更後、/Applications/Quillo.appから起動し、画面タイトル・Qの表示・メニュー名を確認。既存と同じアプリ識別子を使用。

## 自動テスト

`zsh test.sh` のCoreTests、AppearanceTests、PlaybackTests、SlidePanelTests、SlideSummaryTests、SlideTests、PlaybackIntegrationTestsが全て成功。これには実Vision OCR、Unicode表示、長文の最新行への追従、翻訳待ちの集約、古い結果の除外、停止・消去、表示切替でのセッション維持、ローカルモデル限定、要約の短縮とキャッシュ、繁体字の扱いを含む。

この一式は字幕の切替修正時に実行。名称変更は本体の翻訳処理を変更せず、ビルド・署名・実アプリUIを確認。

## 未確認・制約

- 授業1コマを通した連続利用、複数のMac機種、外部ディスプレイ、PowerPoint／Keynoteの各全画面モード、会議ツールでの共有は十分な実地確認をしていない。
- 声・雑音・教材の配置による認識誤り、途中訳の修正、要約の誤りはあり得る。数式や論理条件は元の資料も確認する。
- 対応言語の音声認識・翻訳データ、macOSの権限、Ollamaとモデルの準備が必要。モデルファイルはリポジトリへ含めない。
- Appleによる公証は未実施。配布版の自動更新も未実装。

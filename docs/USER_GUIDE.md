# 使い方・困ったとき

[トップページへ](../README.md) ／ [導入手順](SETUP.md)

## 音声字幕

1. 「授業 → 言語の設定」で「話す言語」（日本語・英語）と「学生に見せる言語」を選びます。学生に見せる言語は、字幕の翻訳・資料の要約で共通です。
2. 「話して字幕を出す」で開始します。
3. 「原文のみ」「翻訳のみ」「原文 ＋ 翻訳」を選びます。字幕の途中でも切り替えられます。
4. 「字幕を停止」で音声入力を止めます。

- **字幕を隠す**：表示だけを隠します。音声入力の停止とは別です。
- **消去**：入力を止め、現在の字幕を消します。
- **長い発話**：最新の行へ自動で進みます。手動スクロールは不要です。
- **全文を確認**：「設定 → 動作確認・字幕ログ → テキストで保存」。ログは終了すると消えます。
- **途中の字幕**：認識と翻訳の進行に合わせて、表現が変わることがあります。
- **マイクの許可**：初回にマイクと音声認識を許可すると、通常は次回以降も引き継がれます。アプリの署名を切り替えた直後は再許可が必要な場合があります。許可しても、起動だけではマイクを開始しません。

メニューバーの吹き出しアイコンや「設定 → 音声字幕」からも、**「話して字幕を出す」**でマイクと字幕表示を同時に始められます。「字幕を停止」でマイクを止めます。「字幕を隠す」は表示だけを隠し、入力は続きます。

### 現在の字幕と履歴

- 「設定 → 音声字幕の見た目 → 履歴を表示」でオン／オフを選べます。表示数は「1文」「2文」。初期設定はオン・2文です。
- 日本語・英語・中国語（簡体字／繁体字）の原文・翻訳に共通です。オフでも字幕は続き、オンに戻すと直前の履歴が表示されます。
- 選んだ数の文が収まるよう文字を自動縮小します。現在の文は18ptまで（設定がそれより小さければ、そのサイズ）、履歴は少し小さく表示します。保存した文字サイズ自体は変更しません。
- マイクでは話の間を区切りとして履歴へ送ります。間のない長い説明は約8秒を目安に区切るため、必ずしも文法上の一文とは一致しません。
- 上から「二文前」「一文前」「現在」の順です。前の二文は薄く残り、時間では消えません。新しい文が来ると古い文から入れ替わります。
- 最初の訳と確定した訂正はすぐ反映し、途中訳の書き換えだけを最短0.65秒間隔にします。表示に最大約0.65秒の待ち時間が加わる場合があります。
- 非常に長い文や小さなパネルでは、「長文の続き」と示して末尾を表示します。すべての文を順番に読む方式ではありません。必要に応じてパネルを広げてください。全文は字幕ログに残ります。
- 文の表示調整だけでは訳文の内容は変えません。任意のAI補正は下記の設定で使えます。

- **音声入力**：日本語・英語のみ。表示する言語は中国語の簡体字・繁体字も選べます。
- **言語の変更**：表示する言語は字幕・要約で共通です。話す言語と資料の言語は別々に選べます。字幕の言語を変更した後は、開始ボタンで音声入力を再開してください。
- **文字入力**：「設定 → 動作確認・字幕ログ → 文字入力の言語」で4言語から選べます。簡体字⇄繁体字はMac内で字体を変換。同じ言語を選ぶと原文を表示します。

## 翻訳文をAIで補正（試用）

- 「設定 → 音声字幕の見た目 → 翻訳文をAIで補正（試用）」でオンにします。初期設定はオフです。
- 通常の翻訳を先に表示し、話の区切りで文法・言い回しを補正します。原文は変更せず、要約もしません。授業の辞書と直前の発話を参考にします。
- 要約と同じMac内のOllama・`qwen3.5:9b`を使用。モデルは自動取得しません。
- 補正が約4秒以内に終わらない、AIが未準備、数字・用語・条件表現や意味の照合を通らない場合は通常の訳を残します。次の話の区切りで再試行します。
- 補正した文には字幕の見出し・保存ログに「AI補正」を表示。直前の履歴への補正も、元の発話の位置へ反映します。
- オフにすると、この入力中に補正した文を通常の訳へ戻します。マイクや翻訳は止まりません。
- 補正も誤ることがあります。数字・用語・条件表現のチェックと、AIによる意味の再確認も完全ではありません。

## 資料の要約

1. 「授業 → 言語の設定」で「資料の言語」を選び、「資料の要約 → 資料の画面を選ぶ」を押します。中国語の簡体字・繁体字も選べます。
2. Mac標準の画面で、Canva・PowerPointなどのウィンドウを選びます。
3. プレビューで資料の部分をドラッグして囲み、「この範囲で要約」を押します。
4. 要約が別のパネルに表示されます。スライドが変わると自動更新します。

- **画面の共有**：選んだ画面をQuilloが読む許可です。インターネット配信ではありません。
- **読み取る範囲**：ブラウザーのタブや操作ボタンを避けて囲みます。離れた複数箇所も選べます。
- **複数範囲の対応**：選択枠の1・2・3と同じ番号で、一つの要約パネル内を分けます（英語ならArea 1など）。文字が見つからない範囲も番号を残します。各範囲を順に処理し、できた要約から表示します。
- **範囲を変更**：選んだ枠をそのまま調整できます。枠の中をドラッグすると移動、角や辺をドラッグするとサイズ変更。枠のない場所を囲むと追加できます。
- **間違えたとき**：「元に戻す」（Command + Z）で操作を取り消します。「選んだ枠を削除」で、その枠だけ削除できます。「キャンセル」は変更を適用せずに戻ります。
- **調整の確定**：「この範囲で要約」を押すと、新しい範囲から要約し直します。画面の選び直しは不要です。枠同士が重なる変更は適用されません。
- **要約し直す**：同じページをもう一度処理します。
- **要約を隠す**：パネルだけを隠します。「停止」は読み取りも終了します。
- **表示言語**：音声字幕と共通です。同じ言語を選べば、その言語で要約します。
- **資料の言語**：話す言語とは独立しています。資料の言語または表示言語を変えた後は、資料の画面を選び直してください。
- **表示する内容**：短い概要と重要点です。全文訳や手動のページ送りはありません。
- **小さいパネル**：文字を自動縮小し、必要に応じて短く要約し直します。

要約には読み取った文字を使います。図や写真そのものはAIへ渡しません。数式・否定・条件などの重要な箇所は、元の資料も確認してください。

## 位置と見た目

- **移動**：字幕・要約の背景をドラッグ。
- **サイズ変更**：パネル右下のつまみをドラッグ。
- **文字・背景**：「設定 → 音声字幕」または「資料の要約」で調整。
- **位置を固定**：パネルの下にある資料をクリックできるようにします。
- **字幕を画面下へ戻す**：「設定 → 音声字幕 → 画面下に戻す」。
- **別の画面へ字幕を出す**：「パネルのサイズ・表示先 → 表示画面」。

原文と訳文の文字サイズは別々に調整できます。位置・サイズ・配色は次回の起動にも引き継ぎます。

## 用語辞書

- 「授業 → 資料の辞書」で、授業に合う辞書を選びます。
- 「設定 → 用語辞書」で、訳語・別名・読み方を確認できます。
- 「辞書を追加・更新…」でJSONファイルを読み込みます。
- 辞書を変えるときは、音声字幕をいったん停止します。

[辞書ファイルの形式と詳しい仕組み](GLOSSARIES.md)

## 学生に見せる

- 字幕・要約を含む**画面全体**を共有・投影してください。
- 資料ウィンドウ単体の共有には、別パネルは入りません。
- 設定画面は学生に見えない画面へ移すか、閉じてください。
- 画面全体を読み取る場合は、要約パネルを選択範囲の外へ置いてください。

## よくある困りごと

| 状況 | 確認すること |
|---|---|
| マイク字幕が出ない | マイク・音声認識の許可、macOSの音声入力、選択言語のデータを確認。 |
| 毎回、許可を求められる | システム設定 → プライバシーとセキュリティで「マイク」と「音声認識」のQuilloを確認。開発版の更新時は固定の署名を使います。詳しくは[導入手順](SETUP.md)。 |
| 原文は出るが翻訳されない | 翻訳元・翻訳先と表示モードを確認。「翻訳を準備」で再試行し、初回の言語データ取得を確認。準備中のまま進まない場合は「準備をやり直す」。 |
| 中国語を話す言語に選べない | 音声入力は日本語・英語のみです。中国語は翻訳の表示先、資料の言語、文字入力で利用できます。 |
| 翻訳のみの表示が一時的に空になる | 翻訳待ちでは原文を出さない仕様。準備状況を確認。 |
| 要約が出ない | 資料の画面と範囲を選択。Ollamaとモデルを確認し、「要約し直す」。 |
| タブやメニューまで要約される | 「範囲を変更」で、資料の本文だけを囲む。 |
| 文字をすべて読めない | 資料の拡大率・文字の鮮明さ・選択範囲を確認。図の内容は要約対象外。 |
| 停止・再起動後に資料が読まれない | 資料の画面と範囲を選び直す。範囲は終了後に保存されない。 |
| 学生側に字幕が映らない | 資料ウィンドウ単体ではなく、画面全体を共有する。 |

## ショートカット

- `Control + Option + Command + K`：字幕を表示／非表示。
- `Control + Option + Command + L`：字幕の位置を固定／解除。
- `Command + Q`：Quilloを終了。
- 設定画面を閉じてもアプリは動作します。メニューバーの字幕アイコンから操作できます。

## データと確認範囲

- 音声認識・翻訳・要約はMac内で処理します。
- 録音ファイル・録画は作りません。
- 字幕ログはメモリに保持し、手動保存しなければ終了時に消えます。
- 辞書と表示設定はMacに保存します。教材の選択範囲は終了後には保存しません。
- 教室の雑音、長時間利用、外部ディスプレイ、発表アプリの全画面、会議ツールの共有は、使用環境で確認してください。
